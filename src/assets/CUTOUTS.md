# Original-pixel transparent cutouts

Prepared with deterministic Sharp processing after the user selected code-based background removal. Original source files are preserved. No generative image tool was used for these cutouts.

## Method

- Removed only border-connected white/light gray neutral canvas pixels; retained enclosed white components and lettering.
- Used a one-pixel alpha feather at canvas edges. Retained RGB values are copied from the original decoded source without recoloring.
- Trimmed fully transparent outer margins with a small safety padding. Lossless RGBA PNG compression preserves retained pixels.
- Hand-traced the original boundaries for the pale electromagnetic flow meter, SDV and pH probe to clear textured canvas/shadows while preserving the equipment.
- Protected real white product bodies and the BMC/MES circular logo disks with explicit foreground masks. The Central India emblem uses circular protection to remove its baked checkerboard.
- Preserved environmental photography, UI screenshots, diagrams with intentional scene backgrounds and colored logo blocks. Existing genuinely transparent images remain usable as originals.
- Filename collisions use the full original filename plus .png; chlorinator.jpg.png and chlorinator.jpeg.png therefore remain different products.
